Hardware Creator Integration

Elgato Stream Deck 1-Click Setup Guide

Control output switching, per-app volume dials, Chat-Mix balance, Mic Lock, and Audio Profiles with live dynamic OLED key icons on Stream Deck MK.2, XL, Mini, Neo, and Stream Deck + rotary dials.

  1. Step 1
    Open Integrations & API Settings

    Launch Quick Audio Switcher v3.4, click the Settings (Gear Icon), and navigate to the Integrations & API tab.

  2. Step 2
    Click "Install Stream Deck Plugin"

    Clicking Install Stream Deck Plugin automatically enables the loopback Local Control Server on http://127.0.0.1:49152 and launches the bundled com.mtdstudio.quickaudioswitcher.streamDeckPlugin package into your Elgato Stream Deck software.

  3. Step 3
    Drag Actions to Your Keys & Dials

    In the Elgato Stream Deck app, find the Quick Audio Switcher category in the right sidebar and drag Toggle Output Device, Mic Mute Guard, App Volume Dial (Spotify/Discord/Game), Chat-Mix Balance, or Apply Audio Profile onto any key or rotary encoder.

Bundled Plugin Identifier & Loopback Host: com.mtdstudio.quickaudioswitcher.streamDeckPlugin · http://127.0.0.1:49152
Loopback Automation API · 127.0.0.1:49152

Complete Local REST & WebSocket API Reference

Automate Windows audio from Elgato Stream Deck, Touch Portal, AutoHotkey, Node-RED, macro pads, or custom scripts. Strictly bound to 127.0.0.1 (localhost loopback) for 100% network safety. If Bearer Token authentication is enabled in Settings, pass Authorization: Bearer <YOUR_TOKEN>.

GET /api/v1/status
Telemetry & State

Returns current master output/input devices, volume percentage, mute states, active Audio Studio toggles (Auto-Duck, Spatial 3D, Safe Vol, Solo Focus, Call Autopilot), and active profile.

HTTP Loopback Request 
# curl
curl -s http://127.0.0.1:49152/api/v1/status

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/status' -Method Get
GET /api/v1/devices
Device Discovery

Lists all active Windows Core Audio playback (render) and recording (capture) endpoints with their deviceId, friendly name, default state, and current volume level.

HTTP Loopback Request 
# curl
curl -s http://127.0.0.1:49152/api/v1/devices

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/devices' -Method Get
POST /api/v1/devices/switch
Endpoint Switching

Switches the default Windows Multimedia & Communications audio endpoint to the specified deviceId (or cycles favorite output devices if omitted).

JSON Payload: {"deviceId": "..."} 
# curl
curl -X POST http://127.0.0.1:49152/api/v1/devices/switch \
  -H "Content-Type: application/json" \
  -d '{"deviceId": "{0.0.0.00000000}.{d4a8e9c1-1234-4b56-89ab-cdef01234567}"}'

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/devices/switch' `
  -Method Post -ContentType 'application/json' `
  -Body '{"deviceId":"{0.0.0.00000000}.{d4a8e9c1-1234-4b56-89ab-cdef01234567}"}'
POST /api/v1/devices/toggle-mute
Mute Control

Toggles mute state for either the default playback speaker/headset ("role": "render") or default microphone ("role": "capture") and returns the new boolean mute status.

JSON Payload: {"role": "render" | "capture"} 
# curl (Toggle Microphone Mute)
curl -X POST http://127.0.0.1:49152/api/v1/devices/toggle-mute \
  -H "Content-Type: application/json" \
  -d '{"role": "capture"}'

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/devices/toggle-mute' `
  -Method Post -ContentType 'application/json' -Body '{"role":"capture"}'
GET /api/v1/sessions
Per-App Mixer

Lists all active per-application WASAPI audio sessions (e.g., spotify, discord, chrome, cs2) along with their process ID, volume scalar (0.0–1.0), mute state, and routed output endpoint.

HTTP Loopback Request 
# curl
curl -s http://127.0.0.1:49152/api/v1/sessions

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/sessions' -Method Get
POST /api/v1/sessions/volume
Per-App Volume

Sets the normalized volume level (0.0 to 1.0) for a specific application by processName (or pid) without affecting master system volume.

JSON Payload: {"processName": "spotify", "volume": 0.65} 
# curl (Set Spotify to 65%)
curl -X POST http://127.0.0.1:49152/api/v1/sessions/volume \
  -H "Content-Type: application/json" \
  -d '{"processName": "spotify", "volume": 0.65}'

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/sessions/volume' `
  -Method Post -ContentType 'application/json' `
  -Body '{"processName":"spotify","volume":0.65}'
GET POST /api/v1/chatmix
Game / Chat Balance

Reads or adjusts the real-time Game vs. Voice Chat balance slider (-1.0 full Game focus to +1.0 full Voice Chat focus, 0.0 neutral center).

JSON Payload: {"balance": -0.35} 
# GET current Chat-Mix balance
curl -s http://127.0.0.1:49152/api/v1/chatmix

# POST new Chat-Mix balance (-0.35 toward Game audio)
curl -X POST http://127.0.0.1:49152/api/v1/chatmix \
  -H "Content-Type: application/json" \
  -d '{"balance": -0.35}'

# PowerShell
Invoke-RestMethod -Uri 'http://127.0.0.1:49152/api/v1/chatmix' `
  -Method Post -ContentType 'application/json' -Body '{"balance":-0.35}'

WS ws://127.0.0.1:49152/ws
Real-Time Bi-Directional Stream

Real-time push event stream broadcasting instant JSON telemetry whenever master volume, microphone mute state, active playback/capture devices, Chat-Mix balance, or per-app audio sessions change. Powers zero-polling OLED key & rotary encoder updates on Elgato Stream Deck.

WebSocket Event Stream & Client Subscription 
# Connect via curl WebSocket handshake
curl --include --no-buffer \
  -H "Connection: Upgrade" -H "Upgrade: websocket" \
  -H "Sec-WebSocket-Key: SGVsbG9XTWVkaWFTeXN0ZW0=" \
  -H "Sec-WebSocket-Version: 13" http://127.0.0.1:49152/ws

# PowerShell (.NET ClientWebSocket)
$ws = [System.Net.WebSockets.ClientWebSocket]::new()
$ws.ConnectAsync([Uri]'ws://127.0.0.1:49152/ws', [Threading.CancellationToken]::None).Wait()
