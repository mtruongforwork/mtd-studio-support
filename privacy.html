SECTION 01 · CORE GUARANTEE

1. Overview & Zero Personal Data Collection

MTD Studio ("we", "our", or "us") develops native Windows desktop utilities distributed through the official Microsoft Store, including Quick Audio Switcher, Daily Habit Tracker Widget (HabitGrid), Batch File Renamer, Quick Invoice Maker, and AuraDesk. Every MTD Studio application is built on a strict 100% Local-First Privacy Architecture.

  • No Personal Data Collection: Our applications do NOT collect, transmit, harvest, store on external servers, or process any Personally Identifiable Information (PII), such as your name, email address, phone number, physical location, IP address, or biometric identifiers.
  • No Telemetry or Analytics SDKs: We do NOT embed third-party analytics, crash-reporting trackers, fingerprinting scripts, or telemetry frameworks (no Google Analytics, no Application Insights, no Sentry, no Mixpanel).
  • No Advertising or Data Selling/Sharing: Our apps contain zero advertisements and zero ad-tracking SDKs. We never sell, rent, trade, or share user data with any third party under GDPR, CCPA/CPRA, or any global privacy regulation.
  • No Cloud Account Required: None of our applications require user registration, login credentials, or cloud synchronization to function. All user preferences, profiles, and files remain 100% on your local Windows computer.
SECTION 02 · PRODUCT DISCLOSURES

2. Product-Specific Local Processing & System Capabilities

Because our Windows utilities interact with native operating system APIs to deliver hardware and desktop control, Microsoft Store Policy requires clear disclosure of how each capability is used. All processing described below happens 100% locally in memory on your PC.

Store ID: 9PC7TTDCCN2V · Flagship v3.4.2.0

2.1 Quick Audio Switcher — Sound & Device Controller

Quick Audio Switcher is a native Windows 11/10 audio endpoint switcher, per-app volume mixer, Smoked Liquid Glass Dynamic Island, Unified 3-in-1 Taskbar Spectrum Dock, and Side Edge Notch controller. It accesses the following local Windows APIs strictly on-device:

  • Windows Core Audio APIs (WASAPI / MMDevice / AudioSessionControl): Used solely to enumerate local playback (render) and recording (capture) audio devices, switch default endpoints, adjust master and per-application volume/mute states, route application audio streams to user-selected physical devices, balance Game/Voice Chat-Mix, and render the real-time visualizer spectrum from instantaneous peak meter values (IAudioMeterInformation).
  • Microphone Activity State Detection (NEVER Records, Listens To, or Stores Audio): Quick Audio Switcher queries the Windows microphone endpoint status (IAudioEndpointVolume and IAudioSessionManager2) exclusively to check whether the microphone endpoint is currently active or muted in order to show the live status badge ([● LIVE] / [MUTED]), toggle microphone mute on click/hotkey, enforce optional Mic Gain Lock, or automatically duck/pause background music during voice calls (Smart Auto-Duck & Call Autopilot). Quick Audio Switcher NEVER records, listens to, captures, transcribes, stores, or transmits any microphone audio or voice data.
  • WinRT Radios & System Controls (Windows.Devices.Radios, WMI & DDC/CI): Used strictly upon direct user click or slider drag in the Dynamic Island Command Center to toggle local Wi-Fi and Bluetooth radio states, read local battery percentage, and adjust monitor display brightness. No wireless network names (SSIDs), MAC addresses, geolocation coordinates, or paired device identifiers are ever collected or transmitted externally.
  • Now Playing Media Transport Controls (GlobalSystemMediaTransportControlsSessionManager): Used locally to display the currently playing track title, artist, and album cover thumbnail inside the Dynamic Island Media tab and execute user-initiated Play/Pause/Next/Previous commands. Media metadata is held transiently in local memory and is never logged or transmitted.
  • Local Control Server for Elgato Stream Deck (127.0.0.1 Loopback Only): Quick Audio Switcher includes an optional local REST and WebSocket control server (http://127.0.0.1:49152 / ws://127.0.0.1:49152/ws) for the official Elgato Stream Deck plugin and local user automation scripts. This server is disabled by default, binds strictly to the local loopback interface (127.0.0.1 / localhost), is protected by a locally generated cryptographic Bearer token (X-QAS-Token), and is never exposed to external networks or the internet.

Local Storage Path: Configuration is stored locally in %LocalAppData%\QuickAudioSwitcher\settings.json and optional local troubleshooting logs in %LocalAppData%\QuickAudioSwitcher\logs\diagnostic.log (never uploaded automatically).

v3.2.0 · Productivity

2.2 Daily Habit Tracker Widget (HabitGrid)

Daily Habit Tracker Widget (HabitGrid) is an offline desktop habit tracking grid, 365-day GitHub-style streak heatmap, and Pomodoro focus timer.

  • 100% Local-Only Data Storage in %LocalAppData%: All habit definitions, daily check-in logs, streak heatmaps, personal notes, and Pomodoro timer settings are saved exclusively on your local storage drive inside %LocalAppData%\HabitGrid\.
  • Zero Cloud Sync or Behavioral Tracking: Your daily routines, personal goals, and focus session histories are never uploaded to any cloud server or shared with third parties. You may export or import plain JSON backups locally at any time.
v2.4.0 · File Management

2.3 Batch File Renamer

Batch File Renamer is a rule-based bulk file, folder, and photo renaming utility for Windows.

  • User-Selected Local File System Processing Only: The application accesses only the specific files and directories that you explicitly select via the Windows File/Folder Picker or drag-and-drop into the application window.
  • 100% Local Metadata & Undo History in %LocalAppData%: All filename transformations, Regex evaluations, photo EXIF timestamp reads, saved rule presets, and 1-click undo rollback logs execute 100% locally and are stored in %LocalAppData%\BatchFileRenamer\. Neither your filenames nor your file contents are ever transmitted over the network.
v2.1.0 · Business & Finance

2.4 Quick Invoice Maker

Quick Invoice Maker is an offline invoice, estimate, and PDF receipt generator for freelancers and small businesses.

  • 100% Local Financial & Client Data in %LocalAppData%: All company details, business logos, client names, billing addresses, catalog items, tax calculations, and invoice records are stored strictly on your local computer inside %LocalAppData%\QuickInvoiceMaker\.
  • Offline PDF Rendering: PDF invoices and receipts are generated locally in memory and saved directly to the folder you select on your PC. MTD Studio never accesses, transmits, or stores any of your financial or client information.
v1.5.0 · Focus & Workspace

2.5 AuraDesk

AuraDesk is a smart desktop workspace launcher, offline ambient focus soundscape mixer, and productivity scratchpad.

  • 100% Local Workspace & Audio Engine in %LocalAppData%: All ambient audio layers are synthesized and mixed locally without internet streaming. All workspace launch profiles, scratchpad notes, and session timer preferences are stored exclusively in %LocalAppData%\AuraDesk\.

SECTION 05 · DATA RETENTION & DELETION

5. Local Data Storage, JSON Backup & Complete Deletion

Because MTD Studio applications operate 100% locally and do not maintain external user databases, you have immediate, complete control over exporting, backing up, or permanently deleting your data at any time:

  • Quick Audio Switcher: %LocalAppData%\QuickAudioSwitcher\ (settings.json and logs\diagnostic.log)
  • Daily Habit Tracker Widget (HabitGrid): %LocalAppData%\HabitGrid\ (local habit & streak JSON/SQLite files)
  • Batch File Renamer: %LocalAppData%\BatchFileRenamer\ (saved rule presets & local undo rollback history)
  • Quick Invoice Maker: %LocalAppData%\QuickInvoiceMaker\ (local invoice drafts, client address book & settings)
  • AuraDesk: %LocalAppData%\AuraDesk\ (local workspace presets, ambient mixer profiles & scratchpad notes)

Complete Data Deletion Procedure: To erase all data created by any MTD Studio app, uninstall the application via Windows Settings → Apps → Installed Apps → Uninstall, and/or open Windows Run (Win + R), enter %LocalAppData%, and delete the corresponding application folder listed above. Once deleted from your device, no copy exists anywhere else.
